# Fluentio: Math Tests

Served at https://trixwotel.github.io/Fluentio/math/ as the math folder of the Fluentio site (see the main branch).

* **index.html** is the page.
* **triangles.js** makes the Triangle Angles questions: 11 kinds, 20 variants each (220), every one with its triangle drawn to scale.
* **amc.js** makes the AMC 10 Practice problems: 12 classic contest topics, 20 variants each (240), with five choices. A test is 25 problems, easier ones first, scored like the AMC 10 (6 points for right, 1.5 for blank, out of 150).

The test runner and the drawing code are in the main branch's kit folder.

The AMC problems are original, in the style of the contest. Real AMC problems are the MAA's copyright.
