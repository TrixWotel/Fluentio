# Fluentio: Physics Tests

Served at https://trixwotel.github.io/Fluentio/physics/ as the physics folder of the Fluentio site (see the space branch).

* **index.html** is the page, with the formulas.
* **kinematics.js** makes the Kinematics questions: 12 kinds, 20 variants each (240), and every variant draws its own motion graph (position, velocity or acceleration against time).
* **kinematics-lessons.js** is the learning path (3 units) and a short lesson for each kind of question.

The test runner and the graph drawing are in the space branch's kit folder.
